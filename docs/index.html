What it does

A recorder and a motion editor in one window.

◉

Record what you choose

A window, a display, or a single Chrome tab. Drag out a region to keep one pane and leave the toolbar out of frame.

⤢

Clicks become zooms

Click activity is grouped into smooth, eased zooms automatically. Adjust the timing, or let the camera follow the cursor.

▣

A real window frame

An editable light or dark macOS frame with working traffic lights. It holds still while the content zooms underneath.

✦

Cursor you can style

Bounded smooth interpolation, outlined styles, movement tilt, ripple and press effects, and keyboard shortcut badges.

◍

Blur and spotlight

Blur regions with editable size and timing to hide anything private. Add timed spotlights and text callouts on top.

⌂

Stays on your Mac

Recordings are written to ~/Movies/FocusFlow. No account, no upload, no external service.

First run

FocusFlow is signed ad‑hoc rather than with a paid Developer ID, so macOS asks once.

  1. Move it to ApplicationsDrag FocusFlow from the opened disk image into your Applications folder.
  2. Open itThe install command above already clears the download quarantine flag, so it launches normally. If you downloaded the .dmg from the button instead, right‑click the app and choose Open the first time.
  3. Allow Screen RecordingmacOS asks on your first recording. FocusFlow appears under System Settings → Privacy & Security → Screen Recording.
  4. Camera, microphone, Input MonitoringRequested only if you turn those on. Input Monitoring is what draws the shortcut badges; ordinary typed text is never collected.

Good to know

Native microphone recording needs macOS 15+. Browser tab capture needs Chrome, and FocusFlow has to stay open while it records — the companion runs on 127.0.0.1 with a per‑session token and writes every chunk locally.

Not yet implemented: captions, multi‑clip assembly, motion blur, custom background images, and pause/resume for native capture. Chrome capture does support pause and resume.

Build it yourself

Requires macOS 14+ and the Apple Command Line Tools.

$ git clone https://github.com/aadityakumarsah/macflow.git $ cd macflow $ ./build-app.sh && open dist/FocusFlow.app

Run ./check.sh for the test suite, or ./scripts/make-dmg.sh to package your own disk image.
